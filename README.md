
# foto-kiosk

Prosta aplikacja webowa do zarządzania zdjęciami – dodawania, podglądu, pobierania, drukowania i tworzenia galerii.

## Funkcje

- Dodawanie zdjęć przez „Dodaj plik” lub przeciąganie (drag & drop)
- Podgląd zdjęć w galerii (miniatury)
- Pobieranie pojedynczych zdjęć
- Pobieranie wszystkich zdjęć jako archiwum ZIP
- Usuwanie zdjęć z galerii
- Drukowanie wybranego zdjęcia bezpośrednio z aplikacji
- Nowoczesny, responsywny interfejs (gradientowe tło, siatka galerii, animacje)

## Instalacja i uruchomienie

1. Sklonuj repozytorium:
	```
	git clone https://github.com/mplik/foto-kiosk.git
	```
2. Przejdź do katalogu projektu:
	```
	cd foto-kiosk
	```
3. Otwórz plik `index.html` w przeglądarce.

## Wymagania

- Przeglądarka obsługująca JavaScript i HTML5

## Przykłady użycia

- Dodaj zdjęcia z dysku lub przesłane przez Bluetooth
- Zarządzaj galerią: pobieraj, drukuj, usuwaj zdjęcia
- Pobierz całą galerię jako ZIP jednym kliknięciem
